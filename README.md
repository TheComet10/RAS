# RAS
**RAS** stands for **Robotic Arm Simulator**, and, as you can read, it's an opensource application made with unity that simulates a robotic arm. In the future will be added concrete functions that can control real life robotic arms. It has it's own launcher that auto updates to the newest version of the app, and it can be downloaded via the [installer](https://github.com/TheComet10/RAS/wiki/Installer). For now, RAS is only avaible for Windows 10/11.

### What is RAS future?
We will surly add new arms, the possibility to move real life  arms, more supported systems, the colliders, a physics system (otherwise this simulator'll be just a poor one), some textures, maybe some sounds, a TCP/IP protocol to connect with other applications (like LabView), and many other things.

Let us know what you think in the [discussions](https://github.com/TheComet10/RAS/discussions)!
